Cleanup

  1. Prune Docker images and the build cache with docker system prune -a. Done when the disk image reports under 25 GB in use.
  2. Remove Xcode's DerivedData, which Xcode rebuilds on demand. Done when the folder is gone and the next build succeeds.
  3. Delete node_modules in projects untouched for 90 days. Done when every removed project still installs with bun install.
Docker's prune removes stopped containers too; check the list with docker ps -a first.
